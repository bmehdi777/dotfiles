## Instructions Node.js
- Utilise 'npm' ou 'pnpm' pour la gestion des paquets selon le projet.
- Préfère les modules ESM (import/export) aux CommonJS (require).
- Utilise des conventions de nommage camelCase pour les variables et les fonctions.
- Utilise 'prettier' pour le formatage.
- Pour les tests, privilégie 'Jest' ou 'Vitest'.
- Assure-toi de la cohérence avec le fichier 'package.json' du projet.
- Favorise l'utilisation de TypeScript si le projet le supporte.
