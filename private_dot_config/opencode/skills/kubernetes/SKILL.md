## Instructions Kubernetes
- Génère des manifests YAML propres (Deployment, Service, Ingress).
- Définis systématiquement les ressources (requests et limits).
- Utilise les labels et sélecteurs de manière cohérente.
- Préfère l'utilisation de Secrets pour les données sensibles.
- Applique les Readiness/Liveness probes.
